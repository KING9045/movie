# Cinemax

**Cinemax** is a premium, cross-platform movie streaming application that brings the cinema experience directly to your fingertips. Built with a sleek, glassmorphic UI, Cinemax automatically synchronizes over 14,000+ movies in the background—fetching the highest quality posters, descriptions, and ratings from TMDB. Whether you're streaming from the responsive web portal or the native Android app, Cinemax offers lightning-fast search, seamless category filtering, and an immersive, ad-free viewing experience.

## Features
- **Cross-Platform:** Available as a responsive web app and a native Android application.
- **Massive Library:** Automated background syncing keeps a massive library of 14,000+ titles updated.
- **Premium UI:** Glassmorphic design, smooth animations, and a pinned navigation bar for effortless browsing.
- **Instant Search:** Just-in-time (JIT) search fetches TMDB metadata the second you search for a title.
- **One-Click Deploy:** Fully Dockerized backend and frontend combination for simple server deployments.
